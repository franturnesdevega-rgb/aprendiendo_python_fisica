# aprendiendo_python_fisica
# Aprendiendo Python desde Física

Este repositorio recoge ejercicios y pequeños proyectos personales mientras aprendo programación aplicada a la física.

**Objetivo:** desarrollar paso a paso destrezas en análisis de datos, simulación y visualización científica.

## Contenido (por ahora)
- Semana 1: operaciones y gráficas básicas
- Semana 2: ajuste lineal y propagación de errores
- Semana 3: mini-proyecto experimental (por decidir)
